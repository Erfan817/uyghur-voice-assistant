# M0 链路验证协议（一周版）

> 目标：用**真实语音 + 真实问题**决定 ASR 供应商、链路形态（A / A' / B1 / B2）、TTS 模型与成本。
> 硬性退出：ASR 过不了线 → 停，回到产品层讨论交互降级，不进入 M1。
> **先文本、后音频**：T0 只比生成出来的维语文本，文本不过关的链路不进 T1，别浪费合成和盲听的时间。
>
> **2026-10-17 范围调整（D8）**：当前定位是自用 + 作品集，家人语料与盲听推迟。
> 第 1 天的语料可以先用自己录的或合成音频替代，流程不变；别为了"凑齐家人样本"卡住整周。

## 总览

```
第 1 天  语料采集（真机、客厅环境、长辈真实声音）+ 当天转写
第 2 天  ASR 实测（WER + 鉴权形态 + 询价单）
第 3 天  T0 文本对照：四臂跑 20 题，母语者读文本打分
第 4 天  T1 音频：T0 胜者两臂合成 + 盲听
第 5 天  TTS 供给确认 + 五类测试 + 话术定稿
第 6 天  决策记录（链路 / ASR / TTS / 成本四张表）
```

## 第 1 天 · 语料采集

- [ ] 15 题纯维语核心问题：天气 ×3、健康 ×3、家常 ×3、办事 ×3、朗读 ×3（家里人实际会问的，**不要写"例句"**）
- [ ] 方言梯度：按家里长辈实际口音归属（中心 / 和田 / 罗布泊）各录若干条
- [ ] 5 题混说抽查：药名、微信、"交社保"等
- [ ] 录制条件：真机、客厅（电视开着）、长辈真实语速
- [ ] 每条标注：说话人、年龄、口音归属、时长

**产出**：`corpus/` 与一份标注表（CSV）。

## 第 2 天 · ASR 实测

- 候选：阿里云「通用-维吾尔语」（16kHz）、讯飞、Speechmatics（备选）
- 指标：**WER**（词错误率），分纯维语 / 方言 / 混说三组
- 通过线：纯维语 **< 10%**；混说抽查 **< 20%**
- 同步拿询价单：按量计费单价、免费额度、是否有并发限制
- 记录每条错误示例（漏字 / 错词 / 方言崩）

**产出**：WER 表 + 询价单。

## 第 3 天 · T0 文本对照（不录音、不合成）

四臂用**同一批问题、同一层规范化**跑纯文本：

- **A**：LLM 直出维语（最小提示词）
- **A'**：直出 + 人设卡（[persona.md](persona.md)）+ 术语表
- **B1**：Hunyuan-MT 维→汉 → 中文推理 → 汉→维（可自托管；先用硅基流动托管 API 对标质量）
- **B2**：同 B1，但翻译也用对话 LLM（同一 API 三次调用，省一个供应商）

```powershell
.\.venv\Scripts\python.exe eval\run_ab.py --arms "A,A',B1,B2"
.\.venv\Scripts\python.exe eval\blind.py data\eval\run-xxxx.jsonl
```

母语者**读文本**打分（不听听感，只看字面）：可懂、自然、**像不像家里人在说话**。
T0 淘汰一半，只留两臂进第 4 天。

**产出**：80 条文本 + 盲评表 + 两臂名单。

## 第 4 天 · T1 音频盲听

- 只把 T0 的胜者做成音频链路（各 20 题，共 40 条）
- 评审：3 位维语母语者（含家里长辈），不知道臂的对应关系；长辈只听 6–8 条核心题
- 维度（1–5 分）：可懂性、自然度、**人设一致性**；另记：回答正确率、端到端延迟、首音延迟
- 错误逐句标注：语序错 / 夹汉语词 / 术语错 / 答非所问 / 乱编
- 打乱顺序盲评，最后再揭盲

**产出**：评分表 + 错误清单（按频次排序，直接进 M2 的失败问题清单）。

## 第 5 天 · TTS 测试

- 模型：`qwen3-tts-uyghur`（基线）vs `SLED-TTS-Uyghur-UAS-0.2B`（克隆）
- 五类测试句：安慰句 / 疑问句 / 祈使句 / 数字（价格、时间）/ 药名（汉维混合）
- 通过线：可懂性 ≥ 4；自然度 ≥ 3（v1 不苛求）
- 问候/天气/超时话术**定稿并校对**后交 TTS 合成并缓存
- 记录：SLED 克隆需家人本人语音授权，且单次合成上限 20 秒 → 长文本朗读要切块（M3）

**产出**：五类合成样本 + 打分 + 定稿话术。

## 第 6 天 · 决策记录

四张表 + 一个结论，写进 [decisions.md](decisions.md)：

| 表 | 内容 |
|---|---|
| 链路表 | A / A' / B 盲听得分与延迟，选定 M1 主线 |
| ASR 表 | 三供应商 WER + 单价，选定供应商 |
| TTS 表 | 两模型五类得分，选定基线 + 是否启用克隆 |
| 成本表 | 按选定组合重算月成本，对照 50 元红线 |

**退出判定**：ASR 纯维语 WER > 15% 或盲听可懂性 < 3.5 → 暂停写代码，先解决识别与可懂性。

## 通过线汇总

| 项 | 通过线 |
|---|---|
| ASR 纯维语 WER | < 10%（硬线 15%） |
| ASR 混说 WER | < 20% |
| 盲听可懂性 | ≥ 4.0 |
| 盲听自然度 | ≥ 3.0（v1 不苛求） |
| 盲听人设一致性 | ≥ 3.5（B1 通常在这里丢分） |
| 延迟 | A ≤ 3.5s；B ≤ 6.0s（可接受上限） |
| TTS 可懂性 | ≥ 4.0 |
| 月成本 | ≤ 50 元（硬线 80） |
