## D1 · 安卓原生 App

- 技术栈：Kotlin + Jetpack Compose，单 Activity，minSdk 26 / targetSdk 33+
- 录音：`AudioRecord` 16kHz / 16bit / 单声道，Opus 流式上传；录音期间必须挂**前台服务**（Foreground Service），常驻通知"Aynur 正在听"——同时解决国产 ROM 保活与"我在听"的反馈
- 交互：按住说话 + 点按模式（按一下开始 / 再按结束），两种都支持，长辈手抖也能用
- 权限与安装：一切难点发生在**安装时刻、由家人完成**——未知来源安装、麦克风授权、电池白名单、设置城市；使用者拿到手零弹窗零设置
- 首启向导 3 步（维语大字按钮）：① 同意麦克风 ② 选城市 ③ 试说一句，由安装者 5 分钟完成
- 更新：不内置自动更新，家人定期拿新 APK 重装——家人本身就是迭代渠道，符合产品节奏
- 不做：小程序、PWA（讨论后关闭，保留为将来如果安卓路线的退路）

## D2 · 纯维语语料策略

| 类型 | 数量 | 说明 |
|---|---|---|
| 纯维语核心问题 | 15 题 | 天气 / 健康 / 家常 / 办事 / 朗读 各 3 题 |
| 方言梯度 | 按家人实际口音 | 中心 / 和田 / 罗布泊方言各录若干，以家里长辈口音归属为准 |
| 汉维混说抽查 | 5 题 | 药名、微信、"交社保"等必然漏进来的词 |

- ASR 通过线：**纯维语 WER < 10%；混说抽查 WER < 20%**
- 录音条件必须真实：客厅电视背景声、真机麦克风、长辈真实语速（慢、停顿多）

## D3 · 问候与天气

- **打开问候**：App 本地判断"当天首次打开 + 时间段"，服务端生成维语问候模板，TTS 结果按文本缓存
- **天气**：不做 GPS（省权限/省电/省隐私顾虑），**安装者首次设置城市一次**，服务端调免费天气 API（心知 / 和风免费版对单用户够用），早上问候里带一句天气摘要
- **不推送**：一切主动都发生在"打开的那一刻"
- 问候/天气/超时/重说的话术模板需母语者校对后定稿（见 [persona.md](persona.md)）

## D4 · 成本策略（不设红线，自托管优先）

定位是**技术学习项目**（见 D8），成本不是约束条件，**能自己把链路跑通**才是目标。
优先级因此倒过来：**自托管 > 托管 API**。凡是可以自己部署的环节（ASR、TTS、翻译），先自己跑一遍；API 只用于质量对标、兜底和快速验证。

- **仍然记账，但不设上限**：花销用来判断"这条路值不值得继续"，不用来决定"砍不砍功能"。
- **GPU 用已有硬件**：本机 RTX 4060 8G 已跑通 ASR（XLS-R）和 TTS（SLED 0.2B）；需要更大显存时按小时租，不买卡。
- **真正的约束是时间**：自托管会把 M0 从 1 周拉长到 3–4 周，这是学习项目的正常代价。

参考成本（不是约束）：

| 项 | 参考月成本 | 备注 |
|---|---|---|
| 轻量云 2C2G | 30–70 元 | 服务端常驻 |
| GPU | 0（用本机） | 需要时按小时租 |
| ASR + TTS | 0（本地） | 对标：阿里云约 2.8 秒/次、讯飞维语 TTS 2 万元/年 |
| LLM | < 5 元 | DeepSeek |
| 天气 | 0 元 | Open-Meteo |

TTS 缓存仍然要做——不是为了省钱，是为了**首字延迟**：问候、天气、兜底话术是高频固定文本，缓存能把响应从秒级压到毫秒级。

## 链路决策（待 M0 盲听最终确认）

- M0 跑**四臂**：
  - **A**：LLM 直出维语
  - **A'**：直出 + 人设提示词 + 术语表
  - **B1**：Hunyuan-MT 维→汉 → 中文推理 → 汉→维（可自托管，也可先用硅基流动托管 API 对标）
  - **B2**：同一 LLM 自翻中转（同一个 API 翻两次，省一个供应商）
- 评测分两段（**先文本、后音频**）：
  - **T0**：不录音、不合成，只比生成出来的维语文本。文本不过关的链路，不进 T1
  - **T1**：T0 的胜者做成音频链路，再做盲听
- 倾向：M1 先走 A'（人设与语气是陪伴产品的差异点），B1 用于事实类问题；最终以盲听结果为准，不预设结论
- 盲评表必含一维"**像不像家里人在说话**"：B1 的翻译模型不吃提示词，人设会被洗成书面语，这一维就是用来暴露它的

## D8 · 阶段定位：自用 + 作品集

- 2026-10-17 决定：**先只自己试用**，给家里长辈正式使用的事以后再说
- 因此简化：
  - 不做 24 小时常开、不做内网穿透、不买云服务器——本机 `localhost` 跑通即可
  - TTS 参考音可以先用自己或现成样本，不必等家人授权录音
  - M0 的家人语料与盲听推迟，先用自录/合成音频自测
- 因此**不改变**：四臂链路、评测工具、PWA 客户端、本地 TTS、安全兜底——这些都是作品集要展示的部分
- 重新启动家庭部署时，需要补的只有：参考音、常开机器或局域网、家人盲听
