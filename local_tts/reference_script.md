# 参考音录制脚本

本地 TTS 是 zero-shot 克隆，合成时必须有一段 **3–9 秒的参考录音 + 逐字转写**。
输出会沿用这段录音的音色，所以录谁的声音，Aynur 就是谁的声音。

## 录制要求

- 安静房间，关掉电视和音乐；手机离嘴 15–20 厘米
- 正常语速，不要刻意放慢，不要朗读腔
- 录 8–10 秒，读两遍，挑清楚的那遍
- 格式随意：m4a / wav / mp3 都行，我会统一转成 24 kHz
- **本人同意**：这段声音只用于家里的 Aynur，不上传、不公开

## 请照读这一段（逐字，不要改词）

> ياخشىمۇسىز. مەن ئائىلەمدىكىلەر بىلەن بىللە تۇرىمەن. بۈگۈن ھاۋا ياخشى، سىرتقا چىقىپ سەيلە قىلغۇم بار.

中文意思：你好。我和家里人住在一起。今天天气好，我想出去走走。

大约 9 秒。读的时候自然一点，中间可以停一下。

## 录完怎么放

```
local_tts/ref/voice.wav     # 录音文件
local_tts/ref/voice.txt     # 上面那段维语，逐字
```

两个文件放好，重启本地 TTS 服务就会用新音色。

> 如果读的时候改了词，`voice.txt` 必须跟着改成实际读的内容——转写和录音不一致会明显影响音质。
